# SafelyAI.Desktop (Membre 1 : interface)
Prérequis : Windows, .NET 8 SDK. Lancer : `dotnet run` dans ce dossier.
- Thèmes : Themes/DarkTheme.xaml et LightTheme.xaml (bascule dans Paramètres).
- Services/IScanService.cs : contrat à valider avec Membre 3 ; MockScanService simule le moteur.
- Pages secondaires (menaces, quarantaine, réseau...) : squelettes à compléter.
- Restent à faire : notifications/alertes, sélecteur de l'analyse personnalisée, rapports.
